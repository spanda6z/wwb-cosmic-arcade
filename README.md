# Wild White Buffalo ($WWB) — Cosmic Arcade

Gamified retro-futuristic single-page arcade cabinet landing experience for the $WWB Solana token.

**Live:** Open [`index.html`](./index.html) or enable GitHub Pages.

## Features

- **Bootloader** — Simulated 1980s terminal diagnostics + "INSERT COIN / START UP" gate
- **CRT Cabinet** — Scanlines, flicker, high-score tokenomics display
- **3-Reel Slot Machine** — Pure CSS pixel-art White Buffalo / Solana / Wild symbols + physical lever pull
- **Jackpot / Combo logic** — Triple match triggers neon green JACKPOT + screen pulse
- **SOL → $WWB Calculator** — Live conversion (default 1 SOL = 50,000 $WWB)
- **STAMP TOKENS** — Opens Dexscreener with official contract
- **Community Radio** — Twitter & Telegram buttons with neon glow
- **Immutable Ticker** — Contract address always visible: `5T7V8epXn2LeoyxqzkWa1pPStJGGQ2i3cQiUQvw8pump`

## Tech

- Zero frameworks / zero external assets
- Pure HTML + CSS (variables, gradients, box-shadow pixel art, animations) + vanilla JS
- Fixed viewport, mobile-friendly scaling
